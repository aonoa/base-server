# Iteration Template

1. Read project docs and current Git state in both repos.
2. Confirm the active version line, task boundary, paired frontend impact, and generated-code impact.
3. Implement source changes.
4. Regenerate outputs only when required.
5. Verify with the narrowest meaningful backend command set plus paired frontend verification when the user flow can be affected.
6. Update project docs if the work changed decisions or boundaries.
7. Report changed files, frontend/backend impact, verification, remaining risks, and next action.
